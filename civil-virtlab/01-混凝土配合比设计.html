红线一 · 配制强度永远比等级高
fcu,0=fcu,k+1.645σ——σ 是施工管理水平，管理水平差 σ 大、配得更"肥"。试配强度不是拍脑袋加 10%，是按统计保证率（95%）算出来的。
红线二 · 水灰比是强度的命门
保罗米公式 fcu=αa·fb·(C/W−αb)：水灰比越小强度越高，但和易性变差；水灰比超标=强度不达标，泌水离析也是它。现场严禁私自加水。
红线三 · 配合比是试配出来的
基准配合比 → 试拌调坍落度 → 强度试配 3 组 → 校正系数修正。理论算的是起点，实验室拌出来、试块 28d 压出来才算数——不用现场实拌结果验证的配合比都是纸上谈兵。
▸ 模型与公式（确定性演示，无随机数凑结果）
配制强度：fcu,0 = fcu,k + 1.645·σ （σ=5.0 MPa，演示固定） 保罗米公式（碎石 αa=0.53、αb=0.20）： fcu = αa·fb·(C/W − αb) → C/W = fcu,0/(αa·fb) + αb 用水量（碎石 Dmax=20mm，查表简化）： 坍落度 30~50mm → W=195；50~70mm → 205；70~90mm → 215 kg/m³ 砂率（查表简化，随 W/C 与 Dmax）：W/C≈0.5 → 34%；0.6 → 38% 线性插值 容重法：C + W + S + G ≈ 2400 kg/m³；S = (2400−C−W)×Sp；G = 2400−C−W−S 本页为确定性演示，σ、用水量、砂率按常用经验值简化，实际按 JGJ 55 试配确定。

演示模型按 JGJ 55《普通混凝土配合比设计规程》保罗米公式与查表法简化设定；实际配合比必须经试拌、强度试配与校正系数修正。教学演示用，不作为工程配合比依据。
