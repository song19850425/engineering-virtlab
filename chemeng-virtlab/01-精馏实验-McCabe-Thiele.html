红线一 · 最小回流比
R 低于 Rmin，操作线碰平衡线，理论板数无穷大——塔永远达不到分离要求。R 越接近 Rmin，塔越省能耗，但板数飙升。
红线二 · 再沸器干烧
塔釜液面过低还继续加热，再沸器干烧、结焦、烧穿换热管。停车时先停热再停进料。
红线三 · 进料热状况
泡点进料（q=1）q 线竖直；冷液进料 q>1、汽液进料 0<q<1、过热蒸汽 q<0——q 线位置变了，所需板数全变。本实验固定泡点进料。
▸ 模型与公式（确定性演示，无随机数凑结果）
平衡线：y = αx / [1 + (α−1)x] 精馏段操作线：y = (R/(R+1))·x + xD/(R+1) 提馏段操作线：y = (L̄/(L̄−W))·x − (W·xB)/(L̄−W)， L̄ = R·D + q·F 物料衡算：F·xF = D·xD + W·xB （F=100 kmol/h，xD=0.95，xB=0.05，q=1） 最小回流比：q 线与平衡线交点 (xq, yq)，Rmin = (xD−yq)/(yq−xq) 理论板数：从 (xD,xD) 交替水平到操作线、垂直到平衡线，直到 x ≤ xB 本页为确定性图解，α、xF、R 全部可调；结果与手工图解一致。

演示模型按板式精馏 McCabe-Thiele 法设定，苯-甲苯体系相对挥发度取常压平均值。教学演示用，不作为工程依据。
