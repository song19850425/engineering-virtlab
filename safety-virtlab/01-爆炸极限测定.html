红线一 · UEL 以上不是安全区
高于 UEL 只是"此刻"氧不足不爆；通风、置换、稀释过程中浓度必然跌回爆炸区间——动火前必须检测+惰化+置换（GB 30871），而不是凭 UEL 判断安全。
红线二 · 极限随条件漂移
温度升高 LEL 下降、UEL 上升（区间变宽）；压力升高 UEL 上升；惰性气体（N₂、CO₂）收窄区间。本实验固定常温常压，工程上必须按工况修正。
红线三 · 混合气用 Le Chatelier
多元混合气不能只看单一组分：LEL_mix = 1/Σ(yᵢ/LELᵢ)。两种"各自不爆"的气体混一起可能爆；检测报警器必须按混合气口径标定。
▸ 模型与公式（确定性演示，无随机数凑结果）
爆炸极限定义：LEL / UEL（vol%），在 LEL ≤ C ≤ UEL 内遇点火源即爆 常用气体（常压常温，教科书通用值）： 甲烷 CH₄：LEL 5.0 / UEL 15.0 氢气 H₂：LEL 4.0 / UEL 75.0 丙烷 C₃H₈：LEL 2.1 / UEL 9.5 一氧化碳 CO：LEL 12.5 / UEL 74.0 混合气（Le Chatelier 定律）： LEL_mix = 1 / Σ(yᵢ / LELᵢ) UEL_mix = 1 / Σ(yᵢ / UELᵢ) 判定： C < LEL → 贫燃区（不爆，但稀释必经爆炸区） LEL ≤ C ≤ UEL → 爆炸区（点火即爆） C > UEL → 富燃区（不爆，稀释回跌仍危险） 本页为确定性演示：浓度、气体种类全部可调，判定与教科书一致。

演示模型按可燃气体爆炸极限通用数据设定；动火作业安全距离、检测报警设定值须按 GB 30871、GB 50493 及现场工艺文件执行。教学演示用，不作为工程依据。
